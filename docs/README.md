# Documentation map

Use [production/README.md](production/README.md) for all new product and engineering work. Root `AGENTS.md`, `PRODUCT.md`, and `DESIGN.md` define the new Gymaf direction.

`production/` contains the source audit, target PRD, architecture, acceptance criteria, agent backlog, and launch gates. `legacy/` preserves original root reference documents. Existing capture ledgers, fixture builders, screenshots, OCR records, and reference QA in this directory describe the prototype; they are not a production backlog or release certificate.

Do not delete historical evidence as part of an unrelated implementation task. However, historical provenance does not grant rights to publish or ship third-party assets; follow the asset cleanup gate before distribution.
